How data moves in and out of Zoho Recruit

The standard Zoho Recruit platform model: what feeds it, the hiring core, and what it sends out. Your account's own modules, custom fields, candidate sources and status stages come from zoho-recruit/explore.py once API access is open.

Every way a candidate enters ends in the Candidates module. Candidates and Job Openings join through Applications, and interviews, assessments and offers hang off that pairing. Automation fires on record changes and is what sends things back out.

These stages are the defaults. Zoho lets each account rename and add stages, so explore.py redraws this from your real Candidate Status and Application Status picklists.

3. How Claude Code connects through the API

sequenceDiagram
  autonumber
  participant You as You (api-console.zoho.in)
  participant CC as Claude Code
  participant Acc as accounts.zoho.in
  participant Rec as recruit.zoho.in/recruit/v2
  You->>Acc: Create Self Client, generate grant code with scopes
  You->>Acc: Exchange grant code for refresh token (one time)
  You->>CC: Save client id, secret, refresh token as environment secrets
  CC->>Acc: POST /oauth/v2/token (refresh_token grant)
  Acc-->>CC: access_token, valid 1 hour
  CC->>Rec: GET /org, /users, /settings/modules
  CC->>Rec: GET /settings/fields, /layouts, /related_lists per module
  CC->>Rec: GET /{module}?fields=id (record counts only)
  Rec-->>CC: JSON metadata
  CC->>CC: Write snapshot.json and diagram.md (Mermaid)
The explorer only sends GET requests and stores no candidate data, only structure, picklist values and record counts.

API endpoints the explorer reads

EndpointWhat it tells you
GET /orgCompany, edition (corporate / staffing), time zone, currency
GET /usersWho works in the account, their roles and profiles
GET /settings/modulesEvery module, including custom ones
GET /settings/fields?module=XFields, custom fields, picklists (sources, statuses) and lookups between modules
GET /settings/layouts?module=XLayouts per module, such as separate forms per hiring type
GET /settings/related_lists?module=XWhat shows under a record (notes, attachments, interviews)
GET /{Module}?fields=idRecord counts, capped at 2,000 per module by default

To connect your account

  1. At api-console.zoho.in create a Self Client.
  2. Generate a code with scopes ZohoRecruit.modules.ALL,ZohoRecruit.settings.ALL,ZohoRecruit.users.ALL,ZohoRecruit.org.ALL and exchange it for a refresh token.
  3. Allow accounts.zoho.in and recruit.zoho.in in the Claude Code environment's network settings.
  4. Add ZOHO_CLIENT_ID, ZOHO_CLIENT_SECRET and ZOHO_REFRESH_TOKEN as environment secrets, then run python3 zoho-recruit/explore.py.
